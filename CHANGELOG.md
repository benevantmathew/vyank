# Changelog
## Version 0.2.0 - 2026-08-28

- Added `yt-dlp` as the default downloader backend.
- Kept `pytubefix` as an alternate downloader backend.
- Added a top-of-window GUI selector for choosing `yt-dlp` or `pytubefix`.
- Added playlist/channel audio-only handling through the selected backend.
- Added `Video and Audio` mode to download both merged MP4 video and separate audio in one click.
- Improved filename sanitizing for Unicode separator characters and base-letter-only safe filenames.

## Version 0.1.0 - 2026-08-12

- Beta version on Video Downloader
- currently supports youtube urls.
